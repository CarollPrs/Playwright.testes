## 📌 Pré-requisitos

Antes de iniciar, certifique-se de ter os seguintes softwares instalados na sua máquina:

* **Node.js** (versão 18.0 ou superior) — [Baixar no site oficial](https://nodejs.org/)
* **Git** — [Baixar no site oficial](https://git-scm.com/)
* **VS Code** *(recomendado)* — [Baixar no site oficial](https://code.visualstudio.com/)
  * *Extensão recomendada:* **Playwright Test for VS Code** (Microsoft)
